# Portfolio de Fernando Alegre

Web personal con mi experiencia como ingeniero de software backend (Java, Spring Boot), mis habilidades y cómo es mi día a día.

Hecha con React y Vite. Está en español e inglés.

## Cómo correrla

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```

## Estructura

- `src/App.jsx`: toda la página (contenido en español e inglés, estilos y componentes).
- `src/logos/`: logos de las empresas.
- `src/foto-fernando.webp`: foto de perfil.
- `src/Fernando_Alegre_CV.pdf`: CV que se descarga desde la web.
